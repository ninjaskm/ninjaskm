### 🚀 Featured Projects

**Conecta Recife** — Urban reports platform (Recife City Hall challenge) · *Backend, team of 3*
> Spring Boot 4 / Java 21 REST API with PostgreSQL, Flyway migrations, JWT auth with citizen/manager/admin roles, automatic routing of reports to the responsible agency, a 0–100 priority score, and async CSV/JSON import built for ~61k real records from the city's 156 service. *(private repository)*

**Calcula Certo** — Brazilian financial and labor calculators · *Solo, pre-deploy*
> Monorepo with Next.js + Fastify (TypeScript), organized as a modular monolith. 10 calculators with 50 regression cases each, versioned formulas, JWT in HttpOnly cookies, MongoDB and Redis, free/premium plans, PDF export and Mercado Pago integration (sandbox validation in progress). *(private repository)*

**FishingCoop** — Co-op multiplayer fishing game · *Solo, in testing*
> Unity 6 + Netcode for GameObjects with a server-authoritative design: clients send intents, the server validates and decides the outcome. Anti-cheat includes server-generated seeds, reaction-time auditing, RPC throttling and movement auditing. *(private repository)*

**[CarLens](https://github.com/ninjaskm/carlens-app)** — Android app to search and compare cars · *Solo*
> Kotlin app with a Node.js/Express API, MongoDB Atlas, JWT + bcrypt auth, filtering and pagination, an admin approval panel and personalized recommendations based on each user's viewing history.
